Authentication

The Audiory REST API uses OAuth 2.0 Bearer Tokens for authentication. All requests over HTTP must be served via SSL (https://). Pass your API key in the request headers:

HTTP Header Format Required for all requests 
Authorization: Bearer aud_live_89f1390ab2c47e8119020942ff
POST

/v2/releases

Initialize a new release draft and define track metadata, splits, and DSP target platforms.

curl -X POST https://api.audiory.site/v2/releases \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Neon Horizons",
    "primary_artist": "Cyber Pulse",
    "genre": "Synthwave",
    "release_date": "2026-09-15",
    "upc": "888123456789",
    "dsps": ["spotify", "apple_music", "amazon", "tidal"]
  }'
const response = await fetch('https://api.audiory.site/v2/releases', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    title: 'Neon Horizons',
    primary_artist: 'Cyber Pulse',
    genre: 'Synthwave',
    release_date: '2026-09-15',
    dsps: ['spotify', 'apple_music', 'amazon']
  })
});
const data = await response.json();
console.log(data);
import requests

headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}

payload = {
    'title': 'Neon Horizons',
    'primary_artist': 'Cyber Pulse',
    'genre': 'Synthwave',
    'release_date': '2026-09-15',
    'dsps': ['spotify', 'apple_music', 'amazon']
}

response = requests.post('https://api.distro.audiory.site/v2/releases', json=payload, headers=headers)
print(response.json())

Request Body Parameters

Parameter Type Required Description
title string Yes The official track or album title.
primary_artist string Yes Main performing artist name.
release_date string (ISO) Yes Target worldwide delivery date (YYYY-MM-DD).
upc string Optional Custom barcode code. Auto-generated if omitted.
